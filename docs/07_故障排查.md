# 故障排查

先在**无人佩戴电极**的状态下检查电源、电压和接线。涉及人体接触时遵循 [安全说明](../hardware/SAFETY.md)，不要为排障临时插上 USB 或示波器。

| 现象 | 分段检查 |
| --- | --- |
| BW16 `Burn` 灯常亮、RST/重插后仍如此 | 烧录模式状态不能只靠 LED 判断。先排除 Burn 按键卡住、供电不稳、烧录工具占用串口；按具体板型下载流程重新烧录，再仅按 RST 启动。若仍不运行，保存上传日志及电压读数。 |
| CYD `BLE SEARCH` | BW16 BLE 草图是否运行并电池有电、广播名称是否 `BW16-EEG`、双板距离/复位状态；确认不是仍刷着“串口直通”草图。 |
| CYD `BLE NO DATA` | BLE 曾连上，但最近约 2 秒无有效 raw。先看 BW16/EEG 供电、EEG TX→PB2、共地；无佩戴台架上可复位 BW16 后重测。历史上确实出现过断流并在复位后恢复。 |
| 串口打开失败 | 重新枚举 COM 号；关闭 MindViewer、SSCOM、RealTerm、Arduino Serial Monitor 中其它占用端口者；设备管理器检查驱动和数据 USB 线。 |
| HEX 窗口无 `AA AA` | 确认打开的是 CYD 端口、115200 8N1，且终端选择 HEX；屏幕若已 LIVE 而串口无字节，检查流控、串口工具是否在“文本视图”。 |
| 串口是乱码或看似全 `00` | 真正输出是二进制包，ASCII 视图会乱码；校验包长度和 checksum。连续 raw 值为 0 且 `signal=200`，优先检查电极/接触与模块，不先改波特率。 |
| `AA AA 04` 有但没有 `AA AA 20` | 大包约每秒一次，先抓数秒；若一直缺，检查解析器错误、BLE 分段/丢帧与模块版本。 |
| `AA AA 20` 有但 MindViewer 空白 | 本项目没证实 MindViewer 当前版本能用这条流正常出图；先用 HEX 抓 BIN 并本地解析，确认非零样本和 `signal`。该软件可能需要不同采样率、串口协议或设置。 |
| 屏幕尖峰多、波形像被压扁 | LCD 使用线性动态上下限，孤立大尖峰会扩大范围；先保存原始数据，查看尖峰是否总在大包后、是否接触不稳，再考虑离线标注，不能简单调缩放掩盖问题。 |
| 网页只有演示曲线 | `web/` 不带 ws 参数时默认 Demo；运行 `tools/eeg_gateway.py` 并使用终端打印的完整地址。 |
| 网关开着但一直 STALE | 先看 CYD 是否 LIVE；新固件默认用 JSON，旧固件必须加 `--format binary`。状态心跳不代表有 raw。 |
| 串口突然变成 JSON 文本 | 上个程序切换了输出模式；退出占用者，发送带换行的 `binary` 或复位 CYD。 |
| 只有大包或健康字段更新，波形不动 | 检查 EEG UART/电源，健康通知只证明 BW16 链路有活动；本版不会因此显示 LIVE。 |
| 旧 CYD 升级 BW16 后格式错误增加 | 新 BW16 增加了 04 健康通知；先升级 CYD，或在 BW16 关闭 kSendHealth。 |
| 编译说找不到 EegCore.h | Arduino CLI 命令缺少 `--libraries libraries`，或没有在项目根目录执行。 |
| BW16 编译返回成功但有 Access denied | 不能视为成功，需允许工具链写安装目录，重新生成镜像并核对；使用构建工具检查日志。 |
| 网页提示重连且曾长时间卡顿 | 过慢客户端可能超过 64 条待发消息而被明确断开；JSONL 记录与浏览器显示分开核对。 |
| 数据大致每秒 248 个 raw 而非 512 | 这是当前模块的实测量级，不应拿通用 TGAM 样例作硬指标；检查长时间波动、丢包率和芯片设置时记录样本证据。 |

若问题仍在，应保存同一时间的 CYD 串口 `.bin`、BW16 日志（仅无人佩戴可 USB 看）、供电电压及显示状态。日志可分清 EEG→BW16、BW16→BLE、BLE→CYD、CYD→电脑的故障位置。
