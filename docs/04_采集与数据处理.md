# 采集与数据处理

0.2.0 支持 BIN 原始字节流和网关 JSONL 两种记录。它们各自独占串口，不能同时打开同一设备。
历史个人采集、原始 EEG 数据、图表和聊天归档不随公开源码发布。

## 采集原则

主记录使用 CYD 输出的原始二进制流，文件扩展名为 `.bin`。终端 HEX 视图仅用于观察，不能代替原始文件。
记录时保存固件版本、接线拓扑、供电状态、开始和结束时间、断流情况；不要将串口号当成固定设备标识。

电脑 USB 只接无线链路另一端的 CYD。佩戴相关的安全边界见[安全说明](../hardware/SAFETY.md)。
采集数据用于原型调试，不用于诊断或推断个人健康状态。

## 采集和解析

项目提供[采集脚本](../tools/capture_serial.py)，需要 Python 和 `pyserial`。先关闭占用串口的终端或分析软件：

```powershell
python tools/capture_serial.py --port COMx --seconds 30 --out .build/captures/sample.bin
python tools/analyze_capture.py .build/captures/sample.bin
```

将 `COMx` 换成 CYD 当前的串口号。脚本等待 USB 串口稳定，切换到二进制模式并清理模式切换残留，随后才开始记录。
它拒绝覆盖 BIN 或元数据文件，并生成包含时间、字节数、SHA-256 和异常原因的 sidecar。
Ctrl+C 或串口异常会保留已接收字节。DTR/RTS 请求保持 false，但部分 USB 转串口驱动仍可能触发复位。

分析器校验 sidecar 的哈希，并报告校验错误、重同步字节、未知包、格式错误和末尾残包。
输出 CSV / PNG 已存在时不会覆盖。绘图可选安装 matplotlib，解析不依赖它。
BIN 不含硬件采样时刻；根据总采集时长推算的样本时间仅是近似值。

## JSONL 记录和 BIN 回放

```powershell
./.venv/Scripts/python.exe tools/eeg_gateway.py --port COMx --record recordings/session.jsonl
./.venv/Scripts/python.exe tools/eeg_gateway.py --replay .build/captures/sample.bin --sample-rate 248
```

回放命令中的文件由操作者本地采集；项目不附带个人脑电样本。`--sample-rate` 用于没有时间戳的 BIN，
应换成当前设备的已知采样率，结果仍是近似回放。

JSONL 每行包含一条网关消息和诊断信息。它拒绝覆盖旧文件并逐条刷新。网页只缓存有限数量的样本，不能替代长时间记录。
`device_rx_ms` 是 CYD 处理数据时的接收时刻，`host_received_us` 是电脑发布消息时的时刻；二者都不是电极采样时刻。
历史回放显示 REPLAY，不标成实时测量。

## 数据解析

先检查同步字节、长度和校验，再解码 raw。`AA AA 20` 开头的是指标包，不能把其中每个字节都当成 raw 样本。
采样编号表示接收顺序，不保证设备端采样序号；BLE 间断和局部停顿会使按总时长换算的时间轴产生误差。

保留原始 BIN 不变。任何滤波、插值、伪迹标记和绘图都应输出到新文件，注明方法和参数。
不要从未经校准的 EEG 原型数据报告心率或其他健康指标。
