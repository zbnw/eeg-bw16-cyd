# 备份与复原

## 本次修改前快照

源码修改前的回退快照保存在本机 `backups/`，包括本地工作说明；不随公开源码发布。
本机 `.build/`、Arduino SDK 和历史录音不会复制进公开源码候选。

回退固件源码可将快照中的对应草图目录复制回 sketches，重新编译；旧代码不依赖新加入的 EegCore 库。
如果只回退一块板，参照 [版本兼容性](https://github.com/zbnw/eeg-bw16-cyd/wiki/0.2%E5%8D%87%E7%BA%A7%E4%B8%8E%E9%AA%8C%E6%94%B6)。设备回退必须再次烧录，文件回退不会改变设备。
网页和工具需要回退时，恢复对应目录里的旧文件；新增加的文件可以保留不用，不必递归删除整个项目。

## 完整外部备份

现有 create_backup.py 支持只备份工程，不再强制要求 H 盘第三方资料存在。
目标应在项目目录外，必须是已经存在的目录；脚本拒绝同名目录 / ZIP，并禁止把备份写回项目内部造成递归复制。

```powershell
$backupRoot = Read-Host 'Enter an existing directory outside this project'
python tools/create_backup.py --destination $backupRoot --project-only
```

不加 --project-only 会沿用旧流程，检查并复制目标目录中规定名称的第三方 SDK / 软件。
请先确认这些资料确实位于目标目录。脚本默认按当前时间命名，也可用 --name 指定单个目录名。
工程完整备份包含 .build、.tools、本地源码快照和 AGENTS.md，排除可重建的 .venv、__pycache__。
备份目标目录需事先存在，并位于项目目录之外。

备份目录内含 SHA256SUMS.csv；完整校验：

```powershell
python 路径/project/tools/verify_backup.py 路径
```

校验检查缺失、哈希 / 大小变化、额外文件和重复条目。此清单用于一致性校验，不是签名认证。
工具不会向远程服务上传采样或聊天资料。

## 复原

解压到独立位置，校验清单，再安装相应 Arduino 平台、USB 驱动及 Python requirements。
COM 号重新确认。构建清单中的 flashed=false 表示构建工具未烧录；硬件是否已更新以实际烧录记录和 LCD / hello 版本为准。
保留至少一份独立介质备份；同一磁盘上的源码快照仅适合改动回退。
