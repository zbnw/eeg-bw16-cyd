# BW16 EEG 原始字节转发诊断程序

这个独立程序用于检查 EEG 模块是否经 UART 向 BW16 发送数据。它不运行 BLE 主程序：BW16 以 `57600 8N1` 从 `PB2`（Arduino `D5`）接收 EEG 字节，再以 `115200 8N1` 原样转发到 USB/日志串口。

接线为 EEG `TX` → BW16 `PB2`、EEG 数字 `GND` → BW16 `GND`。EEG `RX` 和 BW16 `PB1` 不连接。电源与人体接触条件仍须遵守 [接线说明](https://github.com/zbnw/eeg-bw16-cyd/wiki/EEG%E6%8E%A5%E7%BA%BF%E8%AF%A6%E8%A7%A3) 和 [安全边界](https://github.com/zbnw/eeg-bw16-cyd/wiki/%E5%8E%9F%E5%9E%8B%E5%AE%89%E5%85%A8%E8%BE%B9%E7%95%8C)。

## 如何观察输出

把电脑串口终端设为 BW16 当前枚举端口、`115200` 波特率、**十六进制显示**。程序输出的是原始字节，没有 ASCII 转换、附加空格或换行。例如，数值为零的原始样本包应显示为以下 8 字节：

```text
AA AA 04 80 02 00 00 7D
```

转发器会发送收到的每一个字节，包括指标包、错误包和残包；它不解析、修改或筛选 EEG 流。BW16 复位时可能短暂输出启动 ROM 信息；程序本身不发送诊断文字。改变电脑端终端波特率不会改变 EEG 一侧的 57600 波特率。

## 构建与烧录

目标板型为 `realtek:AmebaD:Ai-Thinker_BW16`，本项目验证时使用 AmebaD core 3.1.7。以下命令在项目根目录运行；`COMx` 必须替换为当前 BW16 端口：

```powershell
arduino-cli compile --fqbn realtek:AmebaD:Ai-Thinker_BW16 --build-path .build/bw16_eeg_reader sketches/bw16_eeg_reader
$bwTools = "$env:LOCALAPPDATA/Arduino15/packages/realtek/tools/ameba_d_tools/1.1.3"
$bwPort = 'COMx' # 改成 BW16 当前端口
Get-FileHash .build/bw16_eeg_reader/km0_km4_image2.bin
Get-FileHash "$bwTools/km0_km4_image2.bin"
# 只有两个哈希相同才继续烧录
& "$bwTools/upload_image_tool_windows.exe" $bwTools $bwPort Ai-Thinker_BW16 Enable Disable 1500000
```

烧录前关闭串口监视器。此板上的厂商烧录器曾能以自动烧录设置工作，但每次仍须在输出中确认 `All images are sent successfully!`。当前安装的 Arduino CLI 上传命令不会自动发现该平台特殊命名的固件镜像。构建、烧录和回退的完整检查步骤见 [升级与验收](https://github.com/zbnw/eeg-bw16-cyd/wiki/0.2%E5%8D%87%E7%BA%A7%E4%B8%8E%E9%AA%8C%E6%94%B6)。

仓库不包含个人 EEG 采集文件；请用本机采集验证字节流。电极接触人体前，断开 USB、下载器、充电器和其它有线设备。UART 共地不构成电气隔离。
