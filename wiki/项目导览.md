# EEG 项目导览

当前源码：0.2.0（2026-09-26）。设备中运行的固件版本需在烧录后确认；源码、镜像和实际运行版本分别记录。

## 项目目标

EEG V6.1 输出单通道数据，BW16 经 UART 接收并通过 BLE 发给 CYD，CYD 显示原始波形并转发到电脑。
底板方向仍是 EEG / BW16 模块的小型载板与引脚引出，不设计完整 ESP32 替代主板。

```text
EEG V6.1 --57600 UART--> BW16 --BLE--> CYD --115200 USB--> 电脑
                                           |              |
                                        LCD 波形      BIN / JSONL / 网页
```

## 当前边界

传输与显示链路有过历史台架验证，新版加入软件回归与可追溯构建。网页现在有电脑端串口网关；
直接打开不带 ws 参数的网页仍是演示模式，历史 BIN 回放明确标记为 REPLAY。

硬件底板仍处于连接规范阶段。固件不执行医学诊断、心率计算或自动去伪迹。
采样率必须以当前设备状态为准，不能直接套用其它模块的示例值。
个人采集数据与聊天归档保留在本地，不作为公开源码的一部分。

本版新增的 BLE 健康统计不能保证无损交付。8 位通知序号只能发现部分间断，USB 的接收样本序号不等于模块产生序号。
