# 开发维护（0.2.0）

## 职责分工

| 目录 | 职责 |
| --- | --- |
| libraries/EegCore/src/EegCore.h | 无动态分配的 UART 包解析、字段解码、BLE 分段重组 |
| sketches/bw16_ble_eeg | UART 收取、有界发送队列、BLE 健康报告 |
| sketches/esp32_cyd_starter | BLE/UART 接收、LCD、BIN/JSON USB 模式 |
| sketches/bw16_eeg_reader | 保留坏字节和残包的原始直通诊断工具 |
| tools/eeg_protocol.py | 电脑端增量解析器 |
| tools/eeg_gateway.py | 本机串口 / 历史回放 → WebSocket，可保存 JSONL |
| tools/capture_serial.py | 不覆盖旧文件的 BIN 记录与 SHA-256 元数据 |
| tools/analyze_capture.py | 包解析、原始 CSV、标记及可选绘图 |
| tools/build_firmware.py | 编译日志、镜像检查及源码 / 镜像哈希 |
| tests | 直接测试共用 C++ 核心、Python 网关和网页状态 |

## 构建约束

当前权威环境为 ESP32 core 3.1.1 和 AmebaD 3.1.7。用项目 CLI，并加 `--libraries libraries`。
默认保持 `board::kUseBleEeg=true`；备用 UART 改为 false 后重新编译。
LCD SPI 引脚、ILI9341 初始化和 40 MHz SPI 频率沿用历史工作版本。

`platformio.ini` 固定 espressif32 版本，并配置本地库目录；其 esp32dev 是兼容目标，
ESP32 core 2/3 的扫描返回类型有条件适配，但本轮若未执行 PlatformIO 编译，不能据此宣称已验证。
BW16 SDK 的 notify() 返回 void，无法提供端到端送达确认；勿将“已提交”计为“已送达”。

`build_firmware.py` 默认生成新目录，拒绝覆盖已存在的发布目录。
AmebaD 后处理脚本可能报权限错误却返回 0，因此检查日志与新镜像是必须步骤。
日志、manifest 和镜像一起保留。不要只复制一个 .bin 而丢失板型、源码哈希和构建信息。

## 软件回归

```powershell
./.venv/Scripts/python.exe -m pip install -r tools/requirements-dev.txt
./.venv/Scripts/python.exe -m unittest discover -s tests -p test_*.py -v
node tests/test_web.js

$env:ZIG_LOCAL_CACHE_DIR = Join-Path (Get-Location) '.build/zig-cache'
$env:ZIG_GLOBAL_CACHE_DIR = Join-Path (Get-Location) '.build/zig-global'
./.venv/Scripts/python.exe -m ziglang c++ -std=c++11 -target x86_64-windows-gnu -I libraries/EegCore/src tests/test_eeg_core.cpp -o .build/tests/eeg_core.exe
./.build/tests/eeg_core.exe
```

首次使用先创建 `.build/tests`。Zig 只用于主机 C++ 测试，不用于烧录。也可用本机 C++11 编译器运行同一测试。
测试使用合成协议帧，不需要私人采样文件。C++ 测试可选地接收一个本机 BIN 路径作附加回放检查。

自动测试覆盖包边界、有符号值、损坏包恢复、字段顺序、错误尾部、BLE 缺帧/重复/回绕、
网页样本超时、会话与导出信息、网关真实 WebSocket 收发。它们不能替代射频、任务调度、LCD 和供电实测。

## 修改流程

先保存可恢复快照；一次改变一个可验证行为；核心协议更改同步两端、电脑解析器、测试和文档。
保持原始 BIN 不变。接入新模块前确认实际长度、字段、供电与引脚，不能仅按通用 TGAM 样例推断。
启动、重连和长时间运行测试按 [验收表](https://github.com/zbnw/eeg-bw16-cyd/wiki/0.2%E5%8D%87%E7%BA%A7%E4%B8%8E%E9%AA%8C%E6%94%B6) 留下证据。
`AGENTS.md`、聊天与原始记录按本地资料处理，不加入公开版本控制。
