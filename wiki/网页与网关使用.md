# EEG 网页与本机网关（0.2.0）

页面默认 DEMO，数据来自浏览器生成器。实时连接和历史回放由电脑运行 tools/eeg_gateway.py 提供。
不需要让 CYD 开 Wi-Fi，也不需要把网页部署到外网。

## 安装与运行

在工程根目录：

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r tools/requirements.txt

# 新 CYD 固件：带版本与链路诊断，保存完整 JSONL
./.venv/Scripts/python.exe tools/eeg_gateway.py --port COMx --record recordings/session-001.jsonl

# 旧固件 / BIN 模式：没有 BLE 层诊断，采样率是用户给出的近似值
./.venv/Scripts/python.exe tools/eeg_gateway.py --port COMx --format binary --sample-rate 248

# 本机 BIN 回放：等首个浏览器连接后开始，结束后不自动循环；仓库不附 EEG 采样
./.venv/Scripts/python.exe tools/eeg_gateway.py --replay .build/captures/sample.bin --sample-rate 248
```

打开终端打印的地址，默认：
`http://127.0.0.1:8080/?ws=ws://127.0.0.1:8765/ws`。
默认仅本机可访问；支持 --http-port / --ws-port 选其它端口。Ctrl+C 退出。
浏览器不能发送串口命令。网关串口断开后每 2 秒重试，JSON 长时间消失时重新协商输出模式。

## 显示与数据

- DEMO：本机合成；LIVE：有新的设备样本；REPLAY：历史记录回放；STALE：没有新样本。
- 状态心跳不会让停止的波形继续显示 LIVE。指标超过 3 秒会清空。
- 8 个原始频段仍在 JSON 的 bands_raw 中；网页 Alpha / Beta / Gamma 各由对应两项相加，柱状图是五组总和的百分比。
- 纵轴单位为 raw 数值，非微伏；横轴按给定采样率或接收速率估计，~ 表示近似。
- 图形每个像素区间绘制原始样本最小 / 最大值，不对导出数据做滤波。
- 网页消息缺口、BLE 间断事件、CYD 队列丢弃、BW16 本地丢弃是不同统计，不相加当作总丢样率。
- CSV 最多保存最近 100000 点，覆盖数量在导出提示里显示。长时间采集请用 --record 或 BIN 采集工具。
- CSV 每行保存采集时的来源、设备、固件、会话和速率，断线后导出不会将旧样本改标成新设备。
- --record 写入新 JSONL 文件并拒绝覆盖。包含健康状态及主机接收时间，可供追溯；当前回放输入仅支持 BIN。

没有新固件报告时，电量和延迟保持未知，不生成伪造数值。
协议见 [PROTOCOL.md](https://github.com/zbnw/eeg-bw16-cyd/wiki/%E7%BD%91%E9%A1%B5%E4%B8%8E%E7%BD%91%E5%85%B3%E5%8D%8F%E8%AE%AE)，烧录和回退见 [升级说明](https://github.com/zbnw/eeg-bw16-cyd/wiki/0.2%E5%8D%87%E7%BA%A7%E4%B8%8E%E9%AA%8C%E6%94%B6)。
