# 接线与上电

## 先辨认模块

以 Sichiray EEG V6.1 器件面朝上、`EEG V6.1` 字样正向可读为基准。右上方四个焊盘依次为 `VCC、RX、TX、GND`；底边四个焊盘从左至右为参考电极、前额电极、前额线屏蔽、参考地电极。照片、版本或排针方向变化时，应以实物丝印和厂家资料重新核实，禁止仅凭线色判断。

**参考地电极与数字 GND 是两种不同网络；前额线屏蔽也不应随意并到数字 GND。** 这四根电极线如何贴附人体，必须以对应模块的正式说明为准。当前项目没有验证可用于临床脑电的电极配置。

## 当前主链路：模块 → BW16 → BLE → CYD

| EEG V6.1 | BW16 裸模块 | 说明 |
| --- | --- | --- |
| `TX` | 引脚 15，`PB2 / LP_UART_RXD`（开发板可能标 `D5`） | 模块输出到 BW16 输入；57600 8N1 |
| `GND` | 引脚 9，系统 GND | UART 必须共地 |
| `RX` | 不接 | 本项目不向模块发送指令 |
| `VCC` | 不接 BW16 电源 | 从 EEG 自己的**稳压 3.3 V** 电源输入 |

BW16 也从适合其板型的电池/稳压电路供电。两组电源正端分开，负端因 GND 连线相通；这种“独立供电”**没有电气隔离**。切勿把单节锂电池直接接到标称 3.3 V 的 EEG VCC，满电电压可高于 3.3 V。BW16 的供电电压也必须按实际开发板而非裸芯片名称核对。

ESP32-CYD 与 BW16 之间仅有 BLE 无线链路，不接任何数据线或地线。CYD 可用 USB 接电脑，仅当佩戴端 BW16/EEG **完全电池供电、没有 USB/充电器/示波器/下载器等任何有线外设**。若佩戴端需要电脑有线连接，本原型缺乏相应医学级隔离，停止人体试验。

## 备用直连调试链路

把 `board_config.h` 里的 `board::kUseBleEeg` 改为 `false` 并重新编译 CYD 后，可用 EEG `TX→CYD GPIO27`、`GND→CYD GND` 直连；EEG `RX` 不接，GPIO22 只是预留。此链路仅用于无电极佩戴的台架测试，尤其在 CYD USB 连接电脑时。

CYD LCD 已验证的 SPI 引脚：MOSI 13、SCLK 14、CS 15、DC 2、RST 4、背光 21。不要误拿这些脚当 EEG UART。LCD 驱动是草图中的直接 ILI9341 SPI 操作，旧版 TFT_eSPI 配置曾使此板型看门狗复位。

## 无人佩戴时的上电检查

1. 断电下核实模块朝向、焊盘、线序和导线连续性；检查 EEG 电极输入与系统 GND 没有意外短接。
2. 分别检查两路电源的正负极、电压及稳压器，确认 3.3 V EEG 电源稳定；首次接通前测量，不要靠串口现象推断电压正确。
3. EEG `TX` 与 BW16 `PB2` 相接，EEG/BW16 GND 共地；确认没有把 `TX` 对 `TX`。
4. 先让 EEG 与 BW16 工作，再开 CYD。CYD 屏幕从 `BLE SEARCH` 到 `BLE LIVE`；无佩戴电极时底部 `SIGNAL 200 / NO CONTACT` 及零附近 raw 值均可能正常。
5. 在 CYD USB 串口用 115200、HEX 显示核对 `AA AA 04...` 和 `AA AA 20...`；若没有数据，按故障排查文档逐段定位。
