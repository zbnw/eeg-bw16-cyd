| BW16 BLE 构建 | PASS | AmebaD 3.1.7，Ai-Thinker_BW16 |
| BW16 原始读取器构建 | PASS | 独立诊断镜像，不能代替 BLE 发送固件 |
| Python 回归 | 12 个测试全部通过，无跳过 | 分块解析、损坏包恢复、HTTP 启动、WebSocket、回放、慢客户端退出、采集中断保护和备份校验 |
| C++ 协议核心 | 本机编译并运行通过 | 共用协议解析、超时、BLE 分段、重复与缺帧处理 |
| JavaScript 状态回归 | PASS | 样本/指标新鲜度、非法输入、重复消息、会话切换、CSV 来源和有界导出 |

| BW16 烧录 | 0.2.0 镜像上传工具报告所有镜像发送成功 | 仍需按 RST 启动，并检查启动日志与 BLE 接收 |

GitHub 准备阶段已把历史采样依赖改成合成协议帧，调整后重新运行完整 Python 回归，12 项全部通过。

网关的完整应用测试发现并修复了 HTTP 服务变量遮蔽模块导致的启动失败；
WebSocket 发送任务也改为每连接一组任务，完整历史回放测试已通过。
日志中的拒绝覆盖错误是测试故意触发的保护分支；asyncio 的慢任务提示不表示测试失败，也不构成实时性保证。

PlatformIO 备用入口未编译。射频重连、LCD watchdog、供电和长时间运行仍需按
[升级验收表](https://github.com/zbnw/eeg-bw16-cyd/wiki/0.2%E5%8D%87%E7%BA%A7%E4%B8%8E%E9%AA%8C%E6%94%B6) 实机验证。历史数据回放成功不代表新固件已经上板运行。

历史原始采集、分析图和聊天归档仅保存在本地，不纳入公开仓库。每个 `.bin` 都是字节流数据，校验通过只说明传输格式正确，不代表生理测量有效。
