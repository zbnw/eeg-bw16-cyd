# Sichiray EEG V6.1 接线说明

本文区分 ESP32-CYD 直连调试线路与 BW16 无线线路。两者的 GPIO 编号不可混用。下述模块参数和焊盘方向沿用项目现有资料，制作 PCB 或连接新批次模块前，应对照实物与厂商最新资料复核。

## 模块接口与方向

项目使用单通道 Sichiray EEG V6.1 模块，当前设置为 `57600 8N1`。项目资料记录其输入和 UART 电平为 3.3 V，并列出 9600、57600 两种波特率；**不要据此推断可以直接接入电池电压或其它电平**。厂商参考：[Sichiray EEG 产品页](https://www.sichiray.com/eeg)。

元件面朝上、`EEG V6.1` 字样可读时，右上方焊盘从上到下为：

| 顺序 | 焊盘 | 用途 |
| --- | --- | --- |
| 1 | `VCC` | 模块稳压电源输入 |
| 2 | `RX` | 模块串口输入，本项目不连接 |
| 3 | `TX` | 模块串口输出 |
| 4 | `GND` | 数字电源与 UART 地 |

同一方向下，下方焊盘从左到右分别是参考电极、额头电极、额头线缆屏蔽、参考地电极。**参考地电极属于人体电极输入，不是数字 `GND`**；除非取得明确的厂商电气说明，不要把参考地电极或额头屏蔽线接到 UART/系统地。

## 主线路：EEG → BW16 → BLE → CYD

BW16 载板与 EEG 模块之间只跨接两条信号网络：

| EEG V6.1 | BW16 裸模块 | 说明 |
| --- | --- | --- |
| `TX` | 15 脚 `PB2 / LP_UART_RXD` | EEG 数据送入 BW16 |
| `GND` | 9 脚系统 `GND` | UART 共地 |

EEG `RX` 不接 BW16，EEG `VCC` 也不接 BW16 的 3.3 V 电源轨。EEG 与 BW16 各自使用经过稳压的电源，但 UART 连接必须共地，因此**两个电源域并非电气隔离**。当前连接规范允许 EEG `TX` 到 BW16 `PB2` 直连；为了后续返修，可预留默认闭合焊桥或 0 Ω 电阻位。实际接入前仍须测量电平。

BW16 裸模块脚位沿用 [Ai-Thinker BW16 V1.2.2 规格书](https://docs.ai-thinker.com/_media/bw16_v1.2.2_product_specification_en.pdf) 中的定义，不能直接套用 BW16-Kit 开发板丝印。CYD 与佩戴端之间仅通过 BLE 无线通信，不连接地线或任何其它导线。

## 备用线路：EEG 直连 CYD 台架调试

| EEG V6.1 | ESP32-CYD |
| --- | --- |
| `TX` | `GPIO27`，UART2 接收 |
| `GND` | CYD `GND` |
| `RX` | 不连接 |
| `VCC` | EEG 本地稳压 3.3 V 电源 |

当前 CYD 固件没有配置 UART 发送脚；`GPIO22` 只是预留且未连接的选项。此线路只用于符合安全边界的台架调试，不能把连接电脑 USB 的 CYD 与佩戴中的电极系统有线相连。

## 独立电池与上电检查

两路电源正极保持分开，但 UART 地连接使电池负极在电气上共参考；“分别用电池”不等于隔离。单节锂电池满电电压可能高于 3.3 V，不得直接接 EEG `VCC`，必须选择覆盖实际电池电压范围的稳压方案。

1. 断电时检查两路 `VCC` 没有连接，EEG `RX` 悬空，四个电极网络均未误接数字地。
2. EEG 单独上电，测量 `VCC` 对 `GND` 是否为 3.3 V。
3. 测量 EEG `TX` 对 EEG `GND` 的电平，确认与接收端兼容。
4. MCU 由其电池上电后，再连接共地与 EEG `TX`。
5. 按 `57600 8N1` 接收，先观察校验错误计数和数据流，再考虑电极测试。

人体接触测试前必须阅读 [原型安全边界](https://github.com/zbnw/eeg-bw16-cyd/wiki/%E5%8E%9F%E5%9E%8B%E5%AE%89%E5%85%A8%E8%BE%B9%E7%95%8C)。
